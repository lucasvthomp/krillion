# Krillion catalog review

Compared with the [previous release](https://github.com/lucasvthomp/krillion/commit/7b697eb60273cf1bbdb1b6595775dd657917a438), this pass added **161,122 answers** and **43,488 alternate names** across **103 banks**.

Catalog rules enforce the prompt’s conditions. For example, species prompts use ranked taxa, fossil imports require an extinct vertebrate classification, and city-name prompts check the name itself. “No bulk source checked” means the prompt stayed with the answers from the [earlier individual review](ANSWER-REVIEW.md). Official rosters have a finite size. Some open prompts need sources with an exact date, population boundary, ranking, or other qualifying fact.

Many additions are scientific names. Alternate names share the entry’s score. [Data sources, methods, and licenses](docs/bank/SOURCES.txt)
